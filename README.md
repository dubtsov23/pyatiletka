# Пятилетка · 五年规划

Играть: https://dubtsov23.github.io/pyatiletka/ (QR-код — `qr.svg`).

Браузерная игра-симулятор региональной политики к занятию «Региональная политика в контексте
развития территорий» (Россия и Китай). Студенты играют командами с телефона: открывают ссылку по
QR-коду, без установки. Интерфейс на русском и китайском.

Автор занятия — Г.Ю. Дубцов. Концепт и план версии на Unity — [CONCEPT.md](CONCEPT.md).
Иллюстрация на заставке (`splash.webp`) — художник UMBRA, 2014.
Музыка (`audio.js`) синтезируется в браузере: 8-битные обработки народных мелодий «Коробейники», «茉莉花» (Жасмин), «两只老虎» (Два тигра, напев Frère Jacques); марш в меню — своя мелодия.

## Как провести
1. Покажите на слайде 15 QR-код, команды по 2–4 человека открывают игру на одном телефоне.
2. Дальше всё по листу преподавателя. Правила те же, что у бумажной «Пятилетки».
3. Игра сама показывает событие пятилетки и сама считает итоги, поэтому расчёт идёт быстрее.
4. В конце спикер называет Экономику, Разрыв и Индекс. Пять уровней регионов вводятся в табло
   преподавателя.
5. Если сети нет, раздайте бумажные листы.

## Файлы
- `index.html`, `style.css` — страница.
- `engine.js` — правила, без интерфейса.
- `i18n.js` — тексты RU/中文.
- `app.js` — экраны и карта.
- Проверка правил: `node tests/engine.test.js`. Тест сверяет пример партии из листа преподавателя
  (Индекс 63) и вариант «ничего не делать» (Индекс 14).

После правки файлов поднимите номер `?v=` в `index.html`, иначе телефоны покажут старую версию из кэша.
